# APEX MOTORS – AR Car Showroom

## Description
An interactive Augmented Reality car showroom built using A-Frame and AR.js. The showroom appears when a Hiro marker is detected.

## Features
- Ferrari F10 3D GLB model.
- 3D primitives: box, sphere and cylinder.
- Animated rotating Ferrari.
- Bouncing sphere animation.
- Clickable sphere that changes colour.
- Clickable silver box that toggles Ferrari information.
- APEX MOTORS showroom label.

## Technologies
- HTML5, JavaScript
- A-Frame 1.6.0
- AR.js 3.4.7
- GLB 3D model

## How to Run
1. Open the project using a local server or HTTPS hosting.
2. Allow camera access.
3. Show the Hiro marker to the camera.
4. Click the sphere or silver box to interact.
